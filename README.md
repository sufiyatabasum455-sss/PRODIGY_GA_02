# Task-02: Image Generation with Pre-trained Models

## Overview

This project is part of my Generative AI Internship at Prodigy InfoTech.

The objective of this task is to generate an image from a text prompt using a pre-trained text-to-image generation model.

## Model Used

- Stable Diffusion XL Turbo
- Hugging Face Diffusers
- PyTorch

## Text Prompt

> A futuristic smart city powered by renewable energy, solar panels on buildings, clean electric transportation, green parks, modern architecture, cinematic lighting, highly detailed digital art.

## Implementation

The project uses the pre-trained **Stable Diffusion XL Turbo** model to convert the given text prompt into an image.

The model was loaded using the Hugging Face Diffusers library and the generated image was saved as:

`generated_image.png`

## Technologies Used

- Python
- PyTorch
- Hugging Face Diffusers
- Stable Diffusion XL Turbo
- Google Colab

## Output

The generated image is included in this repository as:
